# Bio-Visual Neural Core

A wearable Edge-AI assistive system that maps digital RGB camera streams into safe micro-current electrical frequencies to restore visual perception for the visually impaired.

## Structure
- `color_encoder.py`: Python script for local edge optical capture and color-to-frequency mapping.
- `nano_neural_firmware.ino`: C++ Arduino firmware for secure PWM micro-current signal generation.
- `project_documentation.md`: Full academic and technical documentation for hackathon submission.
